Продукт представляет собой сервис бронирования переговорных. Предполагается, что данным сервисом будут мелкие и средние компании с ограниченным количеством переговорных, для упрощения определения их занятости, чтобы снизить затраты административного ресурса на распределение времени доступа переговорных.
Для реализации данного продукта важны следующие сценарии: авторизация пользователя, бронирование, отмена бронирования по указанию пользователя или непотдверждению начала встречи, просмотр занятости комнаты, просмотр участия в переговорах пользователя, закрытие переговорной по техническим причинам.
Критерии успеха продукта: сбои при бронировании (цель: не более 5 процентов), время обработки ключевых операций (цель 2 секунды).
На данном этапе развития продукта не будут реализовываться следующее: интеграция с прочими сервисами, работа с различным устройствами не пользователей (например кнопка закрытия переговорной), бронирование оборудования/мебели, статистика переговорных/пользователей.
